# 🗂️ دامج المستندات (DocMerge)

أداة ويب مجانية ومفتوحة المصدر لدمج ملفات **PDF** والصور في مستند واحد، تعمل بالكامل داخل متصفحك — لا رفع لأي ملف إلى أي خادم، ولا حاجة لتثبيت أي برنامج.

جرّبها مباشرة: افتح `index.html` في أي متصفح حديث، أو انشرها على GitHub Pages باتباع الخطوات أدناه.

---

## ✨ المزايا

- **دمج حقيقي** لملفات PDF متعددة مع الحفاظ على كل صفحاتها، باستخدام مكتبة [pdf-lib](https://pdf-lib.js.org/).
- **دمج الصور** (JPG, PNG, WEBP, GIF) كصفحات ضمن نفس المستند، مع خيارين لحجم الصفحة:
  - **A4 قياسي** مع توجيه تلقائي عمودي/أفقي حسب أبعاد الصورة.
  - **بحجم الصورة نفسها** (بلا هوامش).
- **تحديد صفحات معيّنة** من كل ملف PDF (مثال: `1-3,5`) بدل تضمين الملف كاملًا.
- **تدوير** أي ملف (صورة أو PDF) بمقدار 90° تدريجيًا.
- **ضبط جودة الصور** (أصلية / متوسطة / مضغوطة) للتحكم في حجم الملف الناتج.
- **إعادة ترتيب** الملفات بالسحب والإفلات أو بأزرار الأعلى/الأسفل.
- **إضافة صفحة فاصلة** فارغة اختياريًا بين الملفات.
- معالجة أخطاء واضحة: يكتشف الملفات التالفة أو المحمية بكلمة مرور أو ذات الصيغة غير المدعومة، ويتخطاها دون إيقاف بقية العملية.
- واجهة عربية كاملة (RTL)، بمظهرين فاتح وداكن مريحَين للعين عند الاستخدام الطويل، ويتذكر المتصفح اختيارك.
- **الخصوصية أولًا**: كل شيء يتم بجافاسكربت داخل متصفحك، ولا يُرسل أي ملف إلى أي خادم خارجي.

---

## 🚀 التشغيل محليًا

لا حاجة لأي خطوة بناء أو تثبيت حزم. فقط:

```bash
git clone https://github.com/USERNAME/docmerge.git
cd docmerge
```

ثم افتح ملف `index.html` مباشرة في متصفحك (بالنقر المزدوج عليه)، أو شغّل خادمًا محليًا بسيطًا إن رغبت:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> يتطلب اتصالًا بالإنترنت عند أول تشغيل فقط، لتحميل مكتبة `pdf-lib` والخطوط من الشبكة.

---

## 🌐 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المشروع إليه (أو استخدم هذا المستودع مباشرة إن كنت قد نسخته بالفعل).
2. من داخل المستودع، اذهب إلى **Settings ← Pages**.
3. تحت **Build and deployment**، اختر **Source: Deploy from a branch**، وحدد الفرع `main` والمجلد `/ (root)`، ثم اضغط **Save**.
4. خلال دقيقة أو دقيقتين سيظهر رابط بالشكل:
   `https://USERNAME.github.io/docmerge/`
5. افتح الرابط وجرّب رفع بعض ملفات PDF والصور للتأكد أن كل شيء يعمل.

## 🧱 التقنيات المستخدمة

- HTML / CSS / JavaScript (بدون أي إطار عمل أو خطوة بناء).
- [pdf-lib](https://pdf-lib.js.org/) لإنشاء ودمج ملفات PDF داخل المتصفح، محمّلة عبر cdnjs.
- خطوط Google Fonts (Tajawal وAmiri) للواجهة العربية.

---

## ⚠️ حدود معروفة

- ملفات PDF المحمية بكلمة مرور **حقيقية** لتشفير المحتوى (وليس فقط قيودًا على الطباعة/التعديل) قد لا تُدمج بشكل صحيح، لأن فك التشفير الفعلي غير مدعوم من طرف العميل. يُفضّل إزالة الحماية قبل الدمج.
- الملفات الكبيرة جدًا (مئات الميغابايت) قد تستهلك ذاكرة المتصفح وتُبطئ عملية الدمج، لأن كل المعالجة تتم في الذاكرة محليًا.
- الصيغ غير المدعومة حاليًا (Word، Excel، PowerPoint، ...) يجب تحويلها إلى PDF أو صورة قبل إضافتها.
